## 从这里开始

### [LayerScape · 叠境](https://github.com/splrad/LayerScape)

面向 AutoCAD 的模块化效率工具集，支持 AutoCAD 2018–2027。当前提供 AFR 缺失字体检测与自动替换，后续功能共用统一的安装和管理入口。

[下载最新版本](https://github.com/splrad/LayerScape/releases) · [查看使用说明](https://github.com/splrad/LayerScape#readme) · [报告问题](https://github.com/splrad/LayerScape/issues/new?template=bug-report.yml) · [提出功能建议](https://github.com/splrad/LayerScape/discussions/new?category=ideas)

### [Steward](https://github.com/splrad/steward)

为 SPLRAD 各仓库维护拉取请求、验证、仓库接入、Copilot 说明同步和发布规则。它按当前项目的维护方式设计，不是面向外部部署的通用自动化产品。

[查看项目说明](https://github.com/splrad/steward#readme)

## 关于 SPLRAD

SPLRAD 用来集中维护开源工具、共享自动化和工程软件项目。每个项目独立发布，并在对应仓库提供使用说明、下载入口和反馈渠道。
